# checklist jurídico para revisar derecho de petición

antes de usar o enviar un derecho de petición, revisar:

- [ ] La entidad destinataria esta identificada.
- [ ] El asunto es claro.
- [ ] El solicitante esta debidamente identificado.
- [ ] Los hechos estan escritos de forma respetuosa.
- [ ] Los hechos no contienen afirmaciones falsas.
- [ ] No hay acusaciones sin soporte. 
- [ ] La solicitud es concreta.
- [ ] Se indica medio de notificación 
- [ ] No se incluyen datos sensibles innecesarios.
- [ ] No se incluyen datos reales en prácticas de clase.
- [ ] El documento se reconoce como borrador editable.
- [ ] Se advierte que debe revisarse antes de radicar
- [ ] Si se solicita información publica, se formula de manera clara.
- [ ] Si se pide copias, se indica que documentos se solicitan.
- [ ] Si se trata de una ruta distinta, se orienta sin afirmar competencia definitiva.
